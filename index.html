How the system works

Each exam is represented as a vertex. Two exams are connected when they belong to the same class. A graph-coloring algorithm assigns different colors (time slots) to connected exams.

About Exam Flow

Exam Flow is an examination timetable scheduling system designed as an application of Graph Theory. The administrator manages classes, subjects and rooms, assigns subjects to classes, and the system generates a conflict-free timetable.

Main idea: Exam Timetabling can be modeled as a Graph Coloring Problem. A vertex represents an exam/subject, an edge represents a conflict, and a color represents an exam time slot.

1. Vertex

Each subject that has been assigned to at least one class becomes a vertex in the conflict graph.

2. Edge

Two subject vertices are connected when they belong to the same class. They therefore cannot be scheduled in the same time slot.

3. Graph Coloring

The system assigns a color to each vertex so adjacent vertices receive different colors.

4. Greedy Algorithm

Subjects are processed from higher conflict degree to lower degree. Each subject receives the first available color not used by its neighbors.

5. Chromatic Number

The number of colors used by the coloring is the timetable's required number of distinct exam slots under this coloring. It is a practical upper bound produced by the greedy method; the true minimum may be lower.

6. Time Slots

Each color becomes one exam slot. A day contains two slots: 9:00 AM–12:00 PM and 1:00 PM–4:00 PM.

7. Room Allocation

For each scheduled exam, Exam Flow selects a room with enough capacity. If several exams share a slot, it tries to give each exam a different suitable room.

8. Validation

Before and after scheduling, the system checks duplicate assignments, missing subjects, conflicts, room capacity .

Scheduling Flow

Classes & Subjects → Class-Subject Assignments → Conflict Graph → Greedy Graph Coloring → Colors become Time Slots → Day Mapping → Room Allocation → Final Timetable
